# Stats

The app opens on **Stats**. Use **Archive** to search conversations. Stats refreshes every five seconds while that view and browser tab are visible.

Choose **Date range**, **Chat**, and **Message type** to filter saved-message counts, media counts, activity, and top chats. Date ranges include the last 7, 30, or 90 days, **All saved history**, and **Custom dates**. Custom dates include both selected local calendar days. Message types are **All**, **Text**, **Images**, **Voice notes**, and **Other**.

**Message activity** uses UTC buckets, grouping by day, week, month, or year based on the span of matching messages. **Processing** reports work for the full archive and stays independent of these filters. **Voice notes with text** measures how many filtered saved voice notes have generated text; it does not measure recognition accuracy or complete WhatsApp history.

Stats reflects readable saved data within your archive choices. WhatsApp may have delivered only part of your history. If an update fails, use **Refresh stats**; stale counts are cleared. Remote access uses the same password-protected admin setup described in [MCP and remote access](mcp.md).

For first-time linking and import checks, see [local setup](setup.md). For voice processing, see [transcription](transcription.md).
